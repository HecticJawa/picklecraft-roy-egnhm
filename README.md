# Picklecraft

A goofy Minecraft-style voxel game that runs in the browser on computers and phones.
You spawn next to a pickleball court and can play a full game against nasal-voiced villagers.
Lose, and Big Suit comes out of the forest.

Play: open the GitHub Pages link for this repository.

Controls: WASD + mouse on a computer (click to capture the mouse), touch stick + drag-to-look on phones.
Talk to Dinkleton (yellow jersey, next to the court) to play pickleball.

Built with Three.js r160 (MIT). Not affiliated with Mojang or Minecraft.
